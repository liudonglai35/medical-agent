# Synthetic Dermatology Data Factory

## Purpose

`synthetic/dermatology_annotation_trial_v0.1.json` is generated by `scripts/generate_synthetic_cases.py` for engineering, schema, annotation-workflow, and regression testing.

**It is not real clinical data and must not be used to claim clinical diagnostic accuracy, safety, prevalence, or prospective performance.**

## Determinism

The factory is deterministic: the same `--count` produces the same cases. This makes CI regression reproducible.

## Safety fixtures

The generated cases deliberately encode:

- explicit negation as `ABSENT`;
- omission as `NOT_DOCUMENTED`;
- source provenance on every fact;
- AI inference excluded from the synthetic gold facts;
- missing information referenced separately by diagnosis assessments.

## Generate

```bash
python scripts/generate_synthetic_cases.py --count 100
```
